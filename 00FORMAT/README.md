# 00FORMAT

Folder นี้เก็บ **Template มาตรฐาน** สำหรับการสรุปเนื้อหาแต่ละสัปดาห์ของวิชา JN60101
เพื่อให้ไฟล์สรุปทุกสัปดาห์มีโครงสร้าง หัวข้อ และรูปแบบเดียวกัน

## วิธีใช้งาน

### แบบ Manual
1. Copy ไฟล์ `Template-Week-Summary.md`
2. วางไว้ใน `01LECTURE/WeekXX/` (สร้าง Folder ของสัปดาห์นั้นถ้ายังไม่มี)
3. เปลี่ยนชื่อไฟล์เป็น `JN60101-WeekXX.md`
4. แก้ไข frontmatter (`week`, `date`) และหัวข้อ `# JN60101 - Week __` ให้ตรงกับสัปดาห์จริง
5. เติมเนื้อหาในแต่ละหัวข้อ

### แบบใช้ Obsidian core plugin "Templates"
1. เปิด Settings → Core plugins → เปิดใช้งาน **Templates**
2. Settings → Templates → Template folder location → ตั้งเป็น `00FORMAT`
3. ไปสร้างไฟล์ใหม่ใน `01LECTURE/WeekXX/` แล้วใช้คำสั่ง **Insert template** เลือก `Template-Week-Summary`
4. (ถ้าติดตั้งปลั๊กอิน Templater เพิ่มเติม สามารถใช้ `<% tp.date.now() %>` แทนการกรอกวันที่เองได้)

## โครงสร้างหัวข้อมาตรฐานในไฟล์สรุป

| หัวข้อ | คำอธิบาย |
| --- | --- |
| ข้อมูลทั่วไป | วันที่เรียน, หัวข้อหลักของสัปดาห์ |
| หัวข้อที่เรียน | รายการหัวข้อ/เนื้อหาที่สอนในสัปดาห์นั้น |
| คำศัพท์ใหม่ (Vocabulary) | ตารางคำศัพท์ + คำอ่าน + ความหมาย |
| ไวยากรณ์ (Grammar) | โครงสร้างไวยากรณ์ พร้อมตัวอย่างประโยค |
| บทสนทนา/ตัวอย่างประโยคเพิ่มเติม | ตัวอย่างการใช้งานจริง |
| สรุปสิ่งที่เรียนรู้ | สรุปย่อของสัปดาห์นั้น |
| การบ้าน/สิ่งที่ต้องทบทวน | Checklist สิ่งที่ต้องทำต่อ |
| อ้างอิง/เอกสารประกอบ | ลิงก์ไปเอกสาร/สไลด์/หน้าหนังสือที่เกี่ยวข้อง |

**กติกา:** ไฟล์สรุปทุกไฟล์ต้องมีหัวข้อ `# JN60101 - Week XX` เสมอ และแยกไฟล์ 1 สัปดาห์ต่อ 1 ไฟล์ ห้ามรวมหลายสัปดาห์ไว้ในไฟล์เดียว
