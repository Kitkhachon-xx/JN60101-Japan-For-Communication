# JN60101 - แนวข้อสอบสัปดาห์ที่ 3 (สอบย่อยครั้งที่ 1)

> เนื้อหาส่วน Jiko Shōkai (การแนะนำตัว) แยกออกมาจากสรุปบทที่ 1 ([[01LECTURE/Week01/JN60101-Week01]]) เพราะเป็นหัวข้อที่ใช้สอบย่อยครั้งที่ 1 ในสัปดาห์นี้

## 📋 ข้อมูลการสอบ

- **กำหนดสอบ**: สัปดาห์ที่ 3 (พุธ 23 กันยายน 2569) เวลา 8.00-12.30 น. (ตามตารางเรียนกลุ่ม 1.2-1)
- **เนื้อหาที่สอบ**: บทที่ 1-2 (การแนะนำตัว + การแลกนามบัตร)
- **รูปแบบ**: สอบย่อยครั้งที่ 1 จาก 3 ครั้งตลอดเทอม (ครั้งละ 15 คะแนน จากคะแนนทดสอบย่อยรวม 45 คะแนน — เป็นสัดส่วนคะแนนมากที่สุดของวิชา)
- **เวลาสอบ**: สอบพูดเรียงตามลำดับที่กำหนด คนละ 3 นาที
- **ไม่มีสอบซ่อม**
- **หมายเหตุจากอาจารย์**: จะแจ้งเนื้อหาสอบล่วงหน้าก่อนสอบทุกครั้ง และอาจสลับลำดับการสอบ (แจ้งล่วงหน้า) — ควรใช้เวลาเตรียมตัวมากกว่า 1 คืน

### 📊 โครงสร้างข้อสอบ (รวม 15 คะแนน)

| ส่วน | รายละเอียด | คะแนน |
|---|---|---|
| 1. แนะนำตัว (Jiko Shōkai) | พูดแนะนำตัวเองตามโครงสร้างมาตรฐาน | 5 คะแนน |
| 2. คำศัพท์ | แปลคำศัพท์ไทย → ญี่ปุ่น จำนวน 5 คำ | 5 คะแนน (คำละ 1) |
| 3. ตอบคำถาม | ตอบคำถามปากเปล่า 5 คำถาม (อาจารย์แสดงรูป/ถามสด) | 5 คะแนน (ข้อละ 1) |

### 🗣️ ตัวอย่างรูปแบบคำถามที่อาจออกสอบ (ส่วนที่ 3)

อาจารย์จะแสดงรูปภาพหรือถามสด นักศึกษาต้องตอบเป็นประโยคเต็ม โดยเปิดประโยคด้วยคำเดียวกับที่ถูกถาม เช่น

|---|---|
| Kore wa nan desu ka? (นี่คืออะไร) | Kore wa isu desu. |
| Anohito wa doko kara kimashita ka? (เขามาจากประเทศอะไร) | Anohito wa Nihon kara kimashita. |
| Anohito wa dare desu ka? (เขาคือใคร/ทำอาชีพอะไร) | Anohito wa ginkō-in desu. |
| Kore wa nan no zasshi desu ka? (นี่เป็นนิตยสารอะไร) | Kore wa Nihongo no zasshi desu. |
| Kochira wa nan desu ka? (นี่คืออะไร — ใช้กับสถานที่/สิ่งที่สุภาพกว่า) | Kochira wa uketsuke desu. |

## 🎯 หัวข้อหลักที่ควรเตรียม: Jiko Shōkai (การแนะนำตัว)

### โครงสร้างประโยคแนะนำตัวมาตรฐาน

```
Hajimemashite.
Watashi wa [ชื่อ] desu.
Panyapiwatto no gakusei desu.
Shumi wa [manga / dokusho / eiga] desu.
Dōzo yoroshiku onegaishimasu.
```

| ประโยค | คำแปล |
|---|---|
| Hajimemashite. | ยินดีที่ได้รู้จัก (ใช้ตอนพบกันครั้งแรกเท่านั้น) |
| Watashi wa [ชื่อ] desu. | ฉันชื่อ ... |
| Panyapiwatto no gakusei desu. | เป็นนักศึกษาของปัญญาภิวัฒน์ |
| Shumi wa manga desu. | งานอดิเรกคือการ์ตูน |
| Dōzo yoroshiku onegaishimasu. | ฝากเนื้อฝากตัวด้วยนะครับ/ค่ะ |

### คำศัพท์ที่ต้องใช้ในการแนะนำตัว

| คำศัพท์ | ความหมาย |
|---|---|
| watashi | ฉัน / ผม / ดิฉัน |
| ...wa | คำช่วยระบุประธานของประโยค |
| ...no | คำช่วยแสดงความเป็นเจ้าของ/สังกัด ("ของ...") |
| gakusei | นักศึกษา |
| shumi | งานอดิเรก |
| manga | การ์ตูน |
| dokusho | การอ่านหนังสือ |
| eiga | ภาพยนตร์ |
| Hajimemashite | ยินดีที่ได้รู้จัก |
| Dōzo yoroshiku onegaishimasu | ฝากเนื้อฝากตัวด้วย |

### ไวยากรณ์ที่เกี่ยวข้อง (จากบทที่ 1)

- **N1 wa N2 desu.** — ประโยคบอกเล่า (เช่น Watashi wa gakusei desu.)
- **N1 no N2** — ความเป็นเจ้าของ/สังกัด (เช่น Panyapiwatto no gakusei)
- คำเรียกคน + คำต่อท้ายชื่อ: **...san / ...jin / sensei / gakusei** (ห้ามใช้ san ต่อท้ายชื่อตัวเอง)

### ตัวอย่างบทสนทนาแนะนำตัวแบบทางการ (ใช้ตอนแนะนำผู้อื่นให้รู้จักกัน — อาจออกสอบในรูปแบบสถานการณ์คล้ายกัน)

```
ささき：たかはしさん、こちらは　スミスさんです。
       スミスさんは　ABCフーズの　べんごしです。
スミス：はじめまして。スミスです。よろしく　おねがいします。
たかはし：はじめまして。のぞみデパートの　たかはしです。よろしく　おねがいします。
```

- Sasaki: Takahashi-san, kochira wa Sumisu-san desu. Sumisu-san wa ABC Fūzu no bengoshi desu.
- Sumisu: Hajimemashite. Sumisu desu. Yoroshiku onegaishimasu.
- Takahashi: Hajimemashite. Nozomi Depāto no Takahashi desu. Yoroshiku onegaishimasu.

## ✅ เช็คลิสต์เตรียมสอบ

- [ ] ท่องโครงสร้างประโยคแนะนำตัวให้คล่อง (Hajimemashite → Watashi wa...desu → ...no gakusei desu → Shumi wa...desu → Dōzo yoroshiku onegaishimasu)
- [ ] เตรียมข้อมูลของตัวเองไว้ล่วงหน้า: ชื่อ, สังกัด (Panyapiwatto no gakusei), งานอดิเรก
- [ ] ฝึกออกเสียงให้ชัดเจนถูกต้อง (การออกเสียงมักเป็นส่วนหนึ่งของเกณฑ์ให้คะแนน)
- [ ] ทบทวนคำศัพท์อาชีพ + คำนำหน้า/ต่อท้ายชื่อ (san, sensei, gakusei) จากบทที่ 1
- [ ] ทบทวนเนื้อหาบทที่ 2 (การแลกนามบัตร) เพิ่มเติม เพราะสอบย่อยครั้งที่ 1 ครอบคลุมบทที่ 1-2 ทั้งคู่
